عن التطبيق والتراخيص

Magdi IPTV is a personal WebView player. Embedded IPTVnator backend © 4gray, MIT. HLS.js: Apache 2.0. MPEGTS.js: Apache 2.0. Includes the user's Magdi Tube shell adaptations. Android Auto integration is experimental. Optional public directories: Free-TV/IPTV (github.com/Free-TV/IPTV) and iptv-org/iptv (github.com/iptv-org/iptv). Lists are fetched on request; streams are hosted by third parties. No subscription is included.
